# Sprint 3 Day 2: Tier 2 Curriculum Engine

## Goals
- Algorithmic space complexity
- Recursion
- Backtracking

## Mission Overview (20-25 missions)

### 1. Space Complexity Analysis (ELO 1250-1300)
- Big-O notation for space complexity
- Distinguishing time vs space complexity
- Calculating space complexity of basic data structures
- Memory footprint of primitive vs reference types

### 2. Recursive Function Conversion (ELO 1250-1300)
- Converting iterative loops to recursive functions
- Tail recursion optimization
- Base case and recursive case design

### 3. Divide and Conquer (ELO 1300-1350)
- Merge sort implementation
- Quick sort pivot selection strategies
- Binary search on sorted arrays
- Recurrence relations and Master Theorem

### 4. Memoization (ELO 1300-1350)
- Top-down memoization with dictionaries
- Bottom-up tabulation
- Fibonacci and factorial with memoization
- Cache eviction strategies (LRU)

### 5. Recursion Depth Limits (ELO 1300-1400)
- Python recursion limit (`sys.getrecursionlimit()`, `sys.setrecursionlimit()`)
- RecursionError handling and recovery
- Trampolines for iterative recursion
- Tail call optimization alternatives

### 6. Backtracking Patterns (ELO 1300-1400)
- N-Queens problem
- Sudoku solver
- Graph coloring
- Hamiltonian path detection

### 7. Space Optimization Challenges (ELO 1350-1400)
- In-place array reversal
- Linked list reversal without extra space
- Generators and lazy evaluation for memory efficiency
- Space complexity reduction from O(n) to O(1)

## Difficulty Range
- **Tier 2 unlock threshold: ELO 1400**
- Missions designed for ELO 1250-1400 range
- Progressive difficulty from basic space analysis to advanced backtracking
